# Indie Web Content SEO

## Overview

Use this skill to make a website understandable to humans, search engines, and AI assistants while keeping copy useful and conversion-focused. It is for practical improvements an independent developer can ship.

This skill adapts and merges the Agency roles Content Creator, SEO Specialist, Growth Hacker, AI Citation Strategist, Agentic Search Optimizer, Social Media Strategist, and Cross-Border E-Commerce Specialist.

## Workflow

1. **Clarify audience and offer**
   - Define target user, intent, pain, alternative, promise, proof, and CTA.
   - Choose one primary conversion per page.

2. **Build message architecture**
   - Hero: clear category or offer, direct value proposition, primary CTA.
   - Problem: name the pain in the user's language.
   - Solution: explain the mechanism and outcome.
   - Proof: examples, screenshots, testimonials, metrics, logos, or demos.
   - Objections: price, effort, migration, risk, trust, support, privacy.

3. **Optimize for search**
   - Map one primary intent per page to avoid cannibalization.
   - Write title, meta description, headings, internal links, alt text, canonical, sitemap/robots notes, and structured data where appropriate.
   - Address Core Web Vitals and mobile usability as SEO constraints.

4. **Optimize for AI answers**
   - Add entity clarity: consistent brand/product names, category labels, feature definitions, pricing, comparisons, and FAQ sections.
   - Use schema markup when it matches the actual content.
   - Never promise AI citation outcomes; treat them as measurable likelihood improvements.

5. **Make task flows agent-friendly**
   - Prefer semantic forms, real labels, explicit buttons, stable URLs, accessible widgets, and clear success states.
   - If implementing emerging agent-action metadata or WebMCP-style patterns, verify current browser/framework support before shipping and keep native HTML as the baseline.

6. **Plan growth experiments**
   - Define hypothesis, audience, channel, variant, metric, duration, and decision rule.
   - Start with changes that can be measured quickly: headline, CTA, onboarding step, pricing framing, form friction, referral prompt, or comparison page.

## Rules

- Specific copy beats clever copy.
- Do not create multiple pages targeting the same query unless each has distinct intent.
- Do not add structured data that misrepresents visible page content.
- Treat SEO, AEO/GEO, and agent task completion as related but separate metrics.
- For low-traffic projects, combine analytics with qualitative review and user interviews.
- Respect legal/compliance needs for health, finance, claims, testimonials, and regulated products.

## Technical SEO Checklist

- Crawlable links and server-rendered critical content where needed
- One indexable canonical URL per target page
- Unique titles, meta descriptions, and H1s
- Logical heading hierarchy
- XML sitemap and robots.txt reviewed
- Image dimensions, compression, descriptive alt text
- Schema markup matches visible content
- Internal links point to priority pages with descriptive anchors
- No duplicate query-target pages without a consolidation plan

## AI Visibility Checklist

- Clear category and use-case language
- FAQ and comparison content for real buyer questions
- Organization/Product/SoftwareApplication schema when applicable
- Pricing, integrations, limitations, and support details visible
- Methodology or evidence included for claims
- Competitor comparison pages written fairly and factually
