# YanLing AI 产品设计平台 — UI 设计方案概览 v2

## 完成内容

为 YanLing（雁翎）AI 产品设计平台创建了完整的界面设计系统与交互原型。

## 设计方向演进

| 版本 | 方向 | 说明 |
|------|------|------|
| v1 | 暖意精密 (Warm Precision) | 暖象牙白 + 陶土，人文编辑感 |
| **v2** | **霓虹匠造 (Neon Craft)** | 深底 + 三色渐变光谱，AI 科技活力 × 设计匠心 |

### v2 关键设计决策

1. **深色底 + 活色光谱**：从 v1 的暖白底转为深靛蓝底 (#090d14)，用紫→青→珊瑚三色渐变替代单一陶土色，既保留温度又注入科技活力
2. **玻璃态卡片**：半透明卡片 + 悬停渐变辉光，替代传统白色卡片和厚重阴影
3. **辉光克制使用**：辉光仅用于卡片悬停、品牌图标、状态指示，不做全屏泛光
4. **衬线保留**：Fraunces 在暗底上形成"科技中的编辑感"，是品牌辨识度的关键锚点
5. **环境氛围**：`body::before` 柔光渐变 + `body::after` 极淡网格，让深色底不沉闷

- `design-prototype/overview.md` — 本文件

### 原型包含的区块

1. Header 导航（固定 + 毛玻璃 + 链接下划线动画）
2. Hero 区域（非对称布局 + 编辑器预览 + 柔光背景）
3. 核心能力 Bento Grid（6 张玻璃态卡片，含霓虹强调卡 + 琥珀推广横幅）
4. 模板库横向滚动
5. 三步使用流程（渐变连接线 + 辉光步骤点）
6. 用户评价（3 条引用）
7. CTA 转化区（渐变柔光背景）
8. Footer（4 列）

### 技术约束

- 纯 HTML/CSS/JS，无需构建步骤
- 所有 CSS 变量可直接迁移至 Next.js + CSS Modules
- WCAG AA 合规（4.5:1 对比度、键盘导航、Focus 可见）
- 尊重 `prefers-reduced-motion`
